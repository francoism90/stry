# ☁️ S3 Object Storage

## 📝 Introduction

S3-compatible object storage is used by **stry** for storing:

- 🖼️ **Conversions** - Thumbnails and image transformations
- 🎬 **Segments** - HLS video chunks for streaming
- 🔐 **Secrets** - HLS encryption keys

> [!NOTE]
> Any Laravel-compatible S3 service that supports signed URLs will work (AWS S3, MinIO, Garage, etc.).

This guide uses [Garage](https://garagehq.deuxfleurs.fr/) as the reference implementation.

---

## 📋 Prerequisites

**Required:**

- Compatible S3 service (Garage, MinIO, AWS S3, etc.)
- [AWS CLI](https://github.com/aws/aws-cli) (provided by Docker container)

---

## 🛠️ Installation (Garage)

### Setup Shell Alias

For easier interaction with the Garage container:

```bash
# Add to ~/.bashrc or ~/.zshrc
alias garage="podman exec -ti systemd-stry-garage /garage"
```

> [!TIP]
> Or use the stry utility: `stry garage` (see [Interaction](interaction.md) guide).

### 1️⃣ Configure Garage

Generate secure keys for your Garage instance:

```bash
# Edit: ~/.config/containers/systemd/stry/config/garage.toml
# Generate keys using: openssl rand -hex 32
```

Update the configuration file with generated keys for:

- RPC secret
- Admin token
- Metrics token

### 2️⃣ Start Garage Container

```bash
systemctl --user start stry-garage
systemctl --user status stry-garage
```

### 3️⃣ Setup Cluster Layout

Follow the [Garage Quick Start](https://garagehq.deuxfleurs.fr/documentation/quick-start/) to initialize your cluster.

> [!IMPORTANT]
> You must create a cluster layout before proceeding with bucket creation.

## 🗄️ Bucket Configuration

### 1️⃣ Create Required Buckets

```bash
garage bucket create conversions
garage bucket create segments
garage bucket create secrets
```

### 2️⃣ Create API Key

Generate an API key for Laravel:

```bash
garage key create laravel-app-key
```

> [!IMPORTANT]
> Save the output! You'll need the **Access Key ID** and **Secret Access Key**.

### 3️⃣ Update Laravel Configuration

Update your `.env` file with the credentials:

```env
AWS_ACCESS_KEY_ID=your_access_key_id
AWS_SECRET_ACCESS_KEY=your_secret_access_key
AWS_DEFAULT_REGION=garage
AWS_BUCKET=conversions
AWS_ENDPOINT=http://systemd-stry-garage:3900
AWS_URL=https://s3.stry.test
```

### 4️⃣ Grant Bucket Permissions

Assign the API key to all buckets:

```bash
garage bucket allow --read --write --owner conversions --key laravel-app-key
garage bucket allow --read --write --owner segments --key laravel-app-key
garage bucket allow --read --write --owner secrets --key laravel-app-key
```

## 🔧 AWS CLI Setup

### 1️⃣ Configure AWS CLI

Setup AWS CLI with your credentials:

```bash
aws configure
```

Enter:

- **Access Key ID**: From step 2️⃣ above
- **Secret Access Key**: From step 2️⃣ above
- **Region**: `garage` (or your preferred region)
- **Output format**: `json`

### 2️⃣ Set Endpoint URL

Export the S3 endpoint for AWS CLI:

```bash
export AWS_ENDPOINT_URL='http://systemd-stry-garage:3900'
```

> [!TIP]
> Add this to your `~/.bashrc` or `~/.zshrc` for persistence.

### 3️⃣ Verify Connection

Test the connection and list buckets:

```bash
aws s3 ls
```

You should see your three buckets listed.

## 🌐 CORS Configuration

### 1️⃣ Update CORS Policy

Edit `containers/runtimes/policies/cors.json` and replace `AllowedOrigins` with your domain(s):

```json
{
  "CORSRules": [
    {
      "AllowedOrigins": ["https://stry.test", "https://your-domain.com"],
      "AllowedMethods": ["GET", "HEAD"],
      "AllowedHeaders": ["*"],
      "MaxAgeSeconds": 3600
    }
  ]
}
```

### 2️⃣ Apply CORS Policies

Apply the policy to all buckets:

```bash
aws s3api put-bucket-cors --bucket conversions --cors-configuration file://containers/runtimes/policies/cors.json
aws s3api put-bucket-cors --bucket segments --cors-configuration file://containers/runtimes/policies/cors.json
aws s3api put-bucket-cors --bucket secrets --cors-configuration file://containers/runtimes/policies/cors.json
```

### 3️⃣ Verify CORS Settings

```bash
aws s3api get-bucket-cors --bucket conversions
```

## ✅ Verification

### Test Upload

```bash
# Create test file
echo "test" > test.txt

# Upload to bucket
aws s3 cp test.txt s3://conversions/test.txt

# List bucket contents
aws s3 ls s3://conversions/

# Download file
aws s3 cp s3://conversions/test.txt downloaded.txt

# Cleanup
rm test.txt downloaded.txt
aws s3 rm s3://conversions/test.txt
```

## 💡 Alternative S3 Providers

### AWS S3

```env
AWS_ACCESS_KEY_ID=your_aws_key
AWS_SECRET_ACCESS_KEY=your_aws_secret
AWS_DEFAULT_REGION=us-east-1
AWS_BUCKET=your-bucket-name
# No AWS_ENDPOINT needed for AWS S3
AWS_URL=https://your-bucket.s3.amazonaws.com
```

### MinIO

```env
AWS_ACCESS_KEY_ID=your_minio_key
AWS_SECRET_ACCESS_KEY=your_minio_secret
AWS_DEFAULT_REGION=us-east-1
AWS_BUCKET=conversions
AWS_ENDPOINT=http://minio:9000
AWS_URL=https://minio.your-domain.com
```

## 🚨 Troubleshooting

> [!TIP]
> **Common Issues:**
>
> - **Connection refused**: Verify Garage container is running
> - **Access denied**: Check API key permissions with `garage key info`
> - **CORS errors**: Verify CORS policy and allowed origins
> - **Upload fails**: Check bucket permissions and disk space
> - **SSL errors**: Ensure proxy is properly configured for S3 endpoint
