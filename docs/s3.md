S3 is used for storing the following objects:

- conversions (thumbs)
- segments (HLS-chucks)
- secrets (HLS-encryption keys)

Any S3 services that work with Laravel are supported.

## Prerequisites

- A compatible S3 service
- MinIO Client `mc` (provided by Docker container)

## Usage

Garage is used in this guide.

1. Make sure Garage is running:

```bash
systemctl --user start stry-garage
systemctl --user status stry-garage
```

1. Follow <https://garagehq.deuxfleurs.fr/documentation/quick-start/>

1. Setup connection using the generated credentials of `.env`:

```bash
export AWS_ACCESS_KEY_ID=xxxx
export AWS_SECRET_ACCESS_KEY=xxxx
export AWS_DEFAULT_REGION='garage'
export AWS_ENDPOINT_URL='http://systemd-stry-garage:3900'

aws --version
```

1. Setup CORS:

```bash
export CORS='{"CORSRules":[{"AllowedHeaders":["*"],"AllowedMethods":["GET"],"AllowedOrigins":["*"]}]}'
aws s3api put-bucket-cors --bucket conversions --cors-configuration $CORS
```

1. Create the required buckets:

```bash
stry garage bucket allow --read --write --owner conversions --key laravel-app-key
```

1. Set anonymous `download` permissions on required buckets:

```bash
mc anonymous set download rustfs/assets
mc anonymous set download rustfs/conversions
mc anonymous set download rustfs/segments
```

## Disable bucket listing (optional)

Disabling bucket listing is optional, but highly **recommended** on production.

1. Export current bucket permissions:

```bash
cd /tmp
mc anonymous get-json rustfs/assets > assets.json
mc anonymous get-json rustfs/conversions > conversions.json
mc anonymous get-json rustfs/segments > segments.json
```

1. Remove the `"s3:ListBucket"` from the `Action` array in each `<bucket>.json` file:

```bash
vi assets.json
vi conversions.json
vi segments.json
```

1. Update the bucket policy:

```bash
mc anonymous set-json assets.json rustfs/assets
mc anonymous set-json conversions.json rustfs/conversions
mc anonymous set-json segments.json rustfs/segments
rm -rf assets.json conversions.json segments.json
```
