S3 is used for storing the following objects:

- conversions (thumbs)
- segments (HLS-chucks)
- secrets (HLS-encryption keys)

Any S3 services that work with Laravel that supports signed URLs is supported.

## Prerequisites

- A compatible Laravel S3 service
- [aws-cli](https://github.com/aws/aws-cli) (provided by Docker container)

## Usage

[Garage](https://garagehq.deuxfleurs.fr/) is used in this guide.

Because Garage is running in a container, you have to set `alias garage="podman exec -ti systemd-stry-garage /garage"` to use the Garage binary inside the container.

> **TIP**: You may want to use `stry garage` instead (see [interaction](interaction.md)), which is a shortcut for the given `garage` alias.

1. Make sure Garage is running:

```bash
systemctl --user start stry-garage
systemctl --user status stry-garage
```

1. Follow <https://garagehq.deuxfleurs.fr/documentation/quick-start/>

1. Create an API key, and update the AWS credentials in `.env`:

```bash
garage key create laravel-app-key
```

1. Create the required buckets:

```bash
stry garage bucket create conversions
stry garage bucket create segments
stry garage bucket create secrets
```

1. Assign the API-key to the buckets:

```bash
stry garage bucket allow --read --write --owner conversions --key laravel-app-key
stry garage bucket allow --read --write --owner segments --key laravel-app-key
stry garage bucket allow --read --write --owner secrets --key laravel-app-key
```

## Using aws-cli

1. Setup connection using the generated credentials of `.env`:

```bash
export AWS_ACCESS_KEY_ID=xxxx
export AWS_SECRET_ACCESS_KEY=xxxx
export AWS_DEFAULT_REGION='garage'
export AWS_ENDPOINT_URL='http://systemd-stry-garage:3900'
```

1. To list buckets:

```bash
aws s3 ls
```
