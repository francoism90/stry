S3 is used for storing the following objects:

- conversions (thumbs)
- segments (HLS-chucks)
- secrets (HLS-encryption keys)

Any S3 services that work with Laravel that supports signed URLs is supported.

## Prerequisites

- A compatible Laravel S3 service
- [aws-cli](https://github.com/aws/aws-cli) (provided by Docker container)

## Installation

[Garage](https://garagehq.deuxfleurs.fr/) is being used as a reference in this guide.

Use <https://garagehq.deuxfleurs.fr/documentation/quick-start/> as a reference to setup Garage.

Because Garage is running in a container, you have to set `alias garage="podman exec -ti systemd-stry-garage /garage"` instead to use the Garage binary inside the container.

> **TIP**: You may want to use `stry garage` instead (see [interaction](interaction.md)), which is a shortcut for the given `garage` alias.

### Setup keys

A `garage.toml` is already provided, please setup own keys using the provided `openssl rand` utilities.

## Usage

Make sure Garage is running:

```bash
systemctl --user start stry-garage
systemctl --user status stry-garage
```

Create an Laravel API key, and update the `AWS_` credentials in `.env` with the given values:

```bash
garage key create laravel-app-key
```

### Create buckets

1. Create the required buckets:

```bash
garage bucket create conversions
garage bucket create segments
garage bucket create secrets
```

1. Assign the API-key to the buckets:

```bash
garage bucket allow --read --write --owner conversions --key laravel-app-key
garage bucket allow --read --write --owner segments --key laravel-app-key
garage bucket allow --read --write --owner secrets --key laravel-app-key
```

### Setup AWS CLI

Setup connection using the generated credentials of `.env` (starting with `AWS_`).

```bash
aws configure
```

Export the S3 endpoint:

```bash
export AWS_ENDPOINT_URL='http://systemd-stry-garage:3900'
```

Validate if the created buckets are listed:

```bash
aws s3 ls
```

### Setup CORS policies

> **NOTE**: Replace the `AllowedOrigins` value of `containers/runtimes/policies/cors.json` with your own domain(s) when needed.

Add CORS (Cross-Origin Resource Sharing) policies using the AWS CLI:

```bash
aws s3api put-bucket-cors --bucket conversions --cors-configuration file://containers/runtimes/policies/cors.json
aws s3api put-bucket-cors --bucket segments --cors-configuration file://containers/runtimes/policies/cors.json
aws s3api put-bucket-cors --bucket secrets --cors-configuration file://containers/runtimes/policies/cors.json
```
