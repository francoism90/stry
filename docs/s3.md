# S3 Object Storage

S3 is used for storing the following objects:

- assets (fonts, icons)
- conversions (thumbs)
- segments (HLS-chucks)
- secrets (HLS-encryption keys)

Any S3 services that work with Laravel are supported.

## Prerequisites

- A compatible S3 service
- MinIO Client `mc` (provided by Docker container)

## Usage

[RustFS](https://github.com/rustfs/rustfs) is used in this guide.

1. Make sure RustFS is running:

```bash
systemctl --user start stry-rustfs
systemctl --user status stry-rustfs
```

1. Setup connection using the generated credentials of `rustfs.env`:

```bash
mc alias set rustfs http://systemd-stry-rustfs:9000 rustfsadmin
```

1. Create the required buckets:

```bash
mc mb rustfs/local
mc mb rustfs/assets
mc mb rustfs/conversions
mc mb rustfs/segments
mc mb rustfs/secrets
```

All buckets created above are **private by default** — no anonymous policy is needed. Signed URLs embed AWS SigV4 credentials in the URL itself, so they authenticate the request without requiring public bucket access.

## CORS

Browsers enforce CORS even on signed URL requests — buckets must respond with `Access-Control-Allow-Origin` headers or the request will be blocked.

Apply the CORS policy from `containers/runtimes/policies/cors.json` to all buckets:

```bash
./bin/setup-s3.sh
```

Verify the configuration:

```bash
aws s3api get-bucket-cors --bucket segments
```
