# S3 Object Storage

S3 is used for storing the following objects:

- assets (fonts, icons)
- conversions (thumbs)
- segments (HLS-chucks)
- secrets (HLS-encryption keys)

Any S3 services that work with Laravel are supported.

## Prerequisites

- A compatible S3 service
- AWS CLI (provided by the container)

## Usage

[RustFS](https://github.com/rustfs/rustfs) is used in this guide.

1. Make sure RustFS is running:

```bash
systemctl --user start stry-rustfs
systemctl --user status stry-rustfs
```

1. Run the setup script:

```bash
./bin/setup-s3.sh
```

This will configure the `mc` alias, create all required buckets, and apply the CORS policy.

All buckets are **private by default** — no anonymous policy is needed. Signed URLs embed AWS SigV4 credentials in the URL itself, so they authenticate the request without requiring public bucket access.

## CORS

Browsers enforce CORS even on signed URL requests — buckets must respond with `Access-Control-Allow-Origin` headers or the request will be blocked. The CORS policy in `containers/runtimes/policies/cors.json` is applied automatically by `setup-s3.sh`.

To verify:

```bash
aws s3api get-bucket-cors --bucket segments
```
