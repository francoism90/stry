To learn more about MinIO, consider reading the following resources:

- <https://min.io/>
- <https://min.io/docs/minio/linux/reference/minio-mc.html>

## Prerequisites

- MinIO up-and-running
- MinIO Client `mc` (included in base-container)

## Usage

1. Make sure minio is up and running:

```bash
systemctl --user start stry-minio
```

1. Setup connection using the generated credentials of `minio.env`:

```bash
mc alias set rustfs https://s3.spiky.test rustfsadmin --insecure
mc admin info rustfs
```

1. Create required buckets (add your own if required):

```bash
mc mb rustfs/local
mc mb rustfs/assets
mc mb rustfs/conversions
mc mb rustfs/segments
mc mb rustfs/secrets
```

1. Set anonymous `download` permissions on required buckets:

```bash
mc anonymous set download rustfs/assets
mc anonymous set download rustfs/conversions
mc anonymous set download rustfs/segments
```

## Disable bucket listing

> **NOTE**: Disabling bucket listing is optional, but highly recommended on production.

1. Export current bucket permissions:

```bash
cd /tmp
mc anonymous get-json rustfs/assets > assets.json
mc anonymous get-json rustfs/conversions > conversions.json
mc anonymous get-json rustfs/segments > segments.json
```

1. Remove the `"s3:ListBucket"` from the `Action` array in each `<bucket>.json` file:

```bash
vi assets.json
vi conversions.json
vi segments.json
```

1. Update the bucket policy:

```bash
mc anonymous set-json assets.json rustfs/assets
mc anonymous set-json conversions.json rustfs/conversions
mc anonymous set-json segments.json rustfs/segments
rm -rf assets.json conversions.json segments.json
```
